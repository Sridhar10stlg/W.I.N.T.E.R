# Month 0: Repository and workflow setup

- **Date:** 2026-10-12 (rules updated 2026-10-19)
- **Status:** Done

## What was done
- Created `CLAUDE.md` and `AI_Guidelines.md` with the working rules, including the no-AI-attribution rule for commits and PRs. On 2026-10-19 the method changed from "Sridhar types everything" to "AI supplies paste-ready code block by block, Sridhar reads and learns" because of the 1-year deadline.
- Added a Claude section to `.gitignore` that ignores only `.claude/settings.local.json`, so the rest of `.claude/` can be shared across laptops.
- Created `.gitattributes` with `* text=auto` to normalize line endings across Windows and Mac.
- Reviewed the branch merge commands and removed `master` from GitHub (default branch switched to `main` first).
- Added the 12-month schedule as section 13 of [plan.md](../../plan.md).

## What was learned
- Syncing the raw `~/.claude` folder between laptops is fragile. Git plus a progress journal is the sync layer.
- `core.autocrlf` is per machine; `.gitattributes` travels with the repo.
- `git checkout <receiver>` then `git merge <source>` merges one branch into another.
- Under `text=auto`, git leaves binary files untouched so they are not corrupted.
- GitHub will not delete the default branch; change the default first.
