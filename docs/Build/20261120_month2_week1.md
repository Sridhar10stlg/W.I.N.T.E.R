## Goal

Stop a long chat from silently losing its start, give the assistant standing rules, and put the conversation in one object so voice, a web page and tools can share it later.

## Decisions made in this week

| Decision | Choice | Why |
|---|---|---|
| Who owns the conversation | A small `Session` object (messages and system prompt); interfaces use it | One place for every conversation rule; no copy per interface. |
| Long chat | Drop the oldest whole exchanges and tell the user (`[note]`); summarising is a later upgrade (open question 15) | Fixes silent forgetting with the least risk. |
| Trimming rules | Priority: system prompt, newest message, first exchange (if it fits), recent exchanges, rest dropped oldest first in whole pairs | Keeps the history a valid conversation. |
| Trim target | Cut down to about 75% of the budget | Fewer trims; believed (unverified) to keep Ollama's reuse of the conversation start. |
| Size estimate | 3 characters per token, rounded up | Measured 3.7 real; the estimate runs high on purpose. |
| Window setting | `LOCAL_AI_CONTEXT_TOKENS` (default 4096, range 1024 to 131072); budget is the window minus a 512-token reply reserve; the same number is sent to Ollama as `num_ctx` | Our budget and the server's window cannot disagree. |
| System prompt | Plain text file `src/winter/prompts/system.txt`, filled with `string.Template`; `load_system_prompt(today)` accepts a date and nothing else | Conversation text can never reach the template. Jinja2 waits for real logic (open question 16). |
| Too-long message | `ConversationTooLongError`; the question is crossed out and the user is told | A user-fixable situation, not a bug. |

## Measured on the Dynabook (2026-11-20, `gemma3:1b`)

| Round | Tokens Ollama read | Result |
|---|---|---|
| Short chat (control) | 56 | Secret recalled. |
| Long chat, default window | 4,057 of 7,426 sent | Secret forgotten; HTTP 200, no warning (silent truncation confirmed). |
| Long chat, `num_ctx: 8192` | 7,426 | Secret recalled; `ollama ps` showed CONTEXT 8192. |

Also: 27,640 characters came to 7,426 tokens (3.7 characters per token). Reading 4,057 tokens took about 22 s, 7,426 tokens about 45 s (1b model, CPU). With `LOCAL_AI_CONTEXT_TOKENS=2048` through the real adapter, `ollama ps` showed CONTEXT 2048 for `gemma3:4b`.

## Verified by hand

- A long chat at `LOCAL_AI_CONTEXT_TOKENS=1024` showed `[note] The conversation got long, so 6 older messages were dropped from the model's memory.` before the answer, and the chat carried on.
- A normal chat at the default window: no note, and the model recalled the first message.

## Lessons

- A passing suite can still be missing tests: `tests/test_system_prompt.py` was never created, and the total (122, not 132) exposed it. Count tests per file.
- Tests must not depend on the shell: a leftover `LOCAL_AI_MODEL_TIER=high` failed a test, so `conftest.py` now clears all configuration variables for every test.
- A "replace this block" instruction removed `return 0` from `main()`; the exit-code tests caught it.
- Measure before building: the experiment changed the estimate (4 to 3 characters per token) and added the reply reserve.
