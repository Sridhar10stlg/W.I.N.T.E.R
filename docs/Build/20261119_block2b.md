## Goal

Change the provider contract before any real adapter exists, so the Ollama adapter (Block 3) is written once against the final shape. Source: the design review in [docs/design/](../design/).

## Decisions made in these blocks

| Decision | Choice | Why |
|---|---|---|
| `generate()` return type | `Reply(text, stop_reason, usage)`, frozen dataclass ([ADR 0008](../design/decisions/0008-reply-object.md)) | Grows by adding optional fields (tool calls in Month 3) without breaking callers. |
| Terminal safety | `safe_for_terminal()` cleans reply and error text | Model output is untrusted; control and bidi characters are removed. |
| Cut-off replies | `[note]` line when `stop_reason == "length"` | A truncated answer is never hidden. |
| Error types | `ProviderTemporaryError`, `ProviderUnavailableError`, `ProviderSetupError` under `ProviderError` ([ADR 0009](../design/decisions/0009-provider-error-hierarchy.md)) | Grouped by what the caller should do: retry, tell the user, fix config. |
| Exit codes | `main()` returns 0 ok, 2 for config or setup problems; 1 is left to Python's own crash | Scripts can tell "fix your setup" from "bug". Unmapped errors show a traceback (fail loud). |
| Retries | One `RetryingProvider` wrapper retries `ProviderTemporaryError` once ([ADR 0010](../design/decisions/0010-timeouts-and-retries.md)) | One layer only, so attempts never multiply. |
| Where the wrapper is added | Only in `build_provider`, at its single `return` | No provider can reach the CLI without it. |
| Timeout | `LOCAL_AI_TIMEOUT_SECONDS`, default 120, range (0, 600] | Slow laptops set their own value. |
| Model choice | `LOCAL_AI_MODEL_TIER=low\|high` (default `low`), `Settings.model` returns the name | Settles open question 5: the user decides, code never guesses. |
